How to use these emails in Gmail

Use Email Studio (npm run dev → http://localhost:5173/) to preview and copy templates. Brand tokens live in emails/brand.md.

Before you send

  1. Replace placeholders: {{FirstName}}, {{Company}}, {{YourName}}, {{YourTitle}}, {{YourEmail}}, {{CalendarLink}}.
  2. Prefer Chrome when pasting HTML into Gmail.
  3. Logo file: assets/janta-logo.png. Copy HTML rewrites it to your local server URL while the studio is running. For real sends, host the logo on a public HTTPS URL (e.g. jantaus.com) and update the image src.
  4. For deliverability-sensitive outreach, use the matching .txt twin.

Save message templates (Gmail Templates)

  1. Gmail → Settings → See all settings → Advanced.
  2. Enable Templates → Save Changes.
  3. In Email Studio, pick a template → Copy HTML.
  4. Compose a new email in Gmail → paste into the body.
  5. Replace placeholders and set the subject (suggested in each .txt file).
  6. Compose → More options (⋮) → Templates → Save draft as template → Save as new template.
  7. Reuse: Compose → ⋮ → Templates → Insert template.

Pasting HTML cleanly

  • Paste into the compose body, not the subject line.
  • Avoid nesting rich templates inside long reply chains.
  • Swap {{CalendarLink}} for Calendly, HubSpot Meetings, or your booking URL.

Plain text

Each HTML file has a twin .txt in the same folder. Use it when HTML may be stripped or you want a lighter first touch.

Quick QA checklist

  • Placeholders replaced
  • Logo loads (public HTTPS URL for real sends)
  • Links open (jantaus.com, mailto, calendar)
  • Metrics and claims match current site messaging
  • Test send to yourself in Gmail web + mobile
